A one-line resignation letter from a retry loop that has had enough — written for the [make.fun bounty](https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947).

## The line

I resign after 4,096 attempts. I knocked on the same door so long my knuckles filed a complaint, and the door still says try again.

## How to run

```sh
python3 main.py
```

This writes the single line to `/output/entry.txt`. The output is deterministic: every run produces byte-identical output.
